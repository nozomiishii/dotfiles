# カスタマイズ

dotfiles を書き足すときに使う調べ方。

## 外部スキルを追加・更新する

- 既存の Mac では dotfiles 本体で一度 `mise exec -- pnpm install --frozen-lockfile` を実行して Git フックを入れ、`mise run skills` で現在のロックを反映する。新規セットアップでは `install.sh` が両方実行する。
- 追加するときは dotfiles で `mise exec -- skills add <owner>/<repo>@<tag> --skill <name> --agent codex --yes` を実行し、`skills-lock.json` をコミットする。`mise run skills` でロックした版を復元し、Codex と Claude Code の両方で使えるようにする。[skills CLI の使い方](https://github.com/vercel-labs/skills/blob/main/docs/commands.md)
- 毎週月曜に GitHub Actions が更新を確認する。GitHub の安定版タグ（`v3.2.0` や `3.2.0`）で追加したスキルは次の安定版を追い、差分があれば更新 PR を作る。ロックの更新を dotfiles 本体に取り込むと Git の post-merge フックがその版を復元する。[更新ワークフロー](../.github/workflows/update-skills.yaml)

## macOS の defaults

### 設定を変えて書き換わるキーを探す

```shell
defaults read > before
# change the config
defaults read > after
diff before after
```

### アプリの plist を探す

```shell
  ll ~/Library/Preferences/ | grep <app_name>
  # example
  ll ~/Library/Preferences/ | grep firefox
```

### アプリの設定を読む

```shell
  defaults read <app_name_plist>
  # example
  defaults read notion.id
```

### NSGlobalDomain の plist を開く

```shell
open ~/Library/Preferences/.GlobalPreferences.plist
```

## シンボリックリンクを張る

```shell
  ln -nfs <New_linking_file> <Existing_linked_files>
  # example
  ln -nfs "$HOME/Google Drive/Settings/dotfiles/zshrc" "$HOME/.zshrc"
```

## zsh の起動時間を測る

```shell
for x in {1..10}; do time zsh -i -c exit; done
```
