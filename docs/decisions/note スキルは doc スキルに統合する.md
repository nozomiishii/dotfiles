# note スキルは doc スキルに統合する

Status: accepted
Date: 2026-08-10

## Context — 判断を迫られた状況

doc スキルと note スキルの使い分けが曖昧だった。doc から note への委譲リンクはあるが逆参照がなく、「ノートに残して」で note 入口から入ると doc の原則 (言葉遣いメモ・書き方) を一度も読まずに本文が書かれる配線の穴があった。実際にノートが doc の文章ガイドラインを通らずに作られた。

## Decision — 決めたこと

- note スキルを削除し、トリガーと brain ノートの置き場判定を doc スキルへ統合する
- doc スキルは文章ガイドライン (原則・書き方) と置き場判定だけを定める
- worktree・frontmatter・PR などの実行手順はスキルに書かず、対象 repo の指示ファイルと既存ファイルの形式に合わせてその場で判断する

## Consequences — 決定がもたらすもの

- どの入口 (「残しておきたい」「ノートに残して」) から入っても同じガイドラインを通る
- スキルが小さくなり、手順の変更は対象 repo 側の指示ファイルだけで済む
- ノート作成の作法の正本は brain repo の指示ファイルになる
