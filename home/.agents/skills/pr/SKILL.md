# PR

対象 PR の CI、コンフリクト、レビューコメントに対応し、マージできる状態まで持っていく。マージはしない。

## 対象 PR

- 引数に PR URL があれば、その PR を対象にする
- URL がなければ、現在のセッションが対象にしている PR を使う
- 対象を特定できなければ、ユーザーに PR URL を確認する

## 対応

CI の失敗やコンフリクトは原因を調べて直し、必要な検証を行って commit、push する。

未解決のレビューコメントは AGENTS.md の「PR のレビューコメント」に従って対応する。

変更後は PR の状態を確認し直す。新しい失敗やコメントがあれば続ける。質問やユーザーの判断待ちになったら、そこで止める。
